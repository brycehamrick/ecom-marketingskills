Site search, merchandising, and personalization for ecommerce catalogs.

## Capabilities

| Integration | Available | Notes |
|-------------|-----------|-------|
| API | ✓ | REST search and merchandising APIs |
| MCP | - | Not available |
| CLI | - | Not available |
| SDK | ✓ | Searchspring Snap JS framework |

## Agent Notes

- **Site search is underinvested relative to its value** — searchers convert at multiples of site average because they arrive with intent.
- **The highest-value report is zero-result queries.** It is simultaneously a product gap list, a synonym list, and a naming problem list. Audit it monthly, per the `site-cro` and `collection-merchandising` skills.
- Merchandising rules let you pin results for high-intent queries and control collection sort order by revenue-per-view rather than the platform default.
- Supports out-of-stock demotion as a rule, which is the automated version of the inventory-aware merchandising the `collection-merchandising` skill recommends.
- **Related skills**: `collection-merchandising`, `site-cro`, `ecommerce-seo`
