# Redo

Returns and package protection platform for Shopify, with free-returns coverage as a conversion mechanic.

## Capabilities

| Integration | Available | Notes |
|-------------|-----------|-------|
| API | ✓ | REST |
| MCP | - | Not available |
| CLI | - | Not available |
| SDK | - | HTTP only |

## Agent Notes

- Sells return coverage as a checkout add-on, which funds free returns without absorbing the cost directly. Relevant where a generous returns policy would otherwise be unaffordable.
- **A clear, generous returns policy stated on the PDP raises conversion**, especially in fit-dependent categories — see `product-pages`. This is the mechanic that makes that affordable.
- Same measurement applies as any returns platform: capture reason codes and track the exchange-to-refund ratio.
- Any add-on presented at checkout must not be pre-selected and its terms must be clear. See `claims-and-compliance`.
- **Related skills**: `post-purchase-experience`, `product-pages`, `cart-and-checkout`
