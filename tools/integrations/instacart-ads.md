# Instacart Ads

Retail media network for grocery and CPG brands selling through Instacart.

## Capabilities

| Integration | Available | Notes |
|-------------|-----------|-------|
| API | ✓ | Ads API, partner access |
| MCP | - | Not available |
| CLI | - | Not available |
| SDK | - | HTTP only |

## Agent Notes

- Relevant only if you have distribution through retailers on Instacart. Like all retail media, **the ad spend is often part of maintaining the retail relationship** rather than a standalone acquisition channel.
- Shopper behavior differs from search marketplaces — basket-building rather than single-item search. Featured product placement and complementary positioning matter more than keyword precision.
- High purchase intent; the shopper is actively filling a cart.
- Model contribution margin after both retailer margin and ad spend. See `wholesale-and-retail` for the underlying margin stack.
- **Related skills**: `marketplace-ads`, `wholesale-and-retail`
