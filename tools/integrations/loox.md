# Loox

Photo-review platform for Shopify, focused on visual UGC collection and display.

## Capabilities

| Integration | Available | Notes |
|-------------|-----------|-------|
| API | ✓ | REST (limited) |
| MCP | - | Not available |
| CLI | - | Not available |
| SDK | - | HTTP only |

## Agent Notes

- **Photo-first is the point.** Photo and video reviews outperform text substantially, and Loox is built around collecting them — which is the specific gap in most brands' review programs.
- Referral module included; treat it as customer-to-friend referral, distinct from affiliate. See `creators-and-affiliates`.
- Incentive for photo reviews must be disclosed and must not be conditioned on a positive rating. See `claims-and-compliance`.
- Less structured-attribute capture than Okendo — if fit or skin-type aggregation matters for the category, that is a reason to choose differently.
- **Related skills**: `reviews-and-reputation`, `product-pages`
